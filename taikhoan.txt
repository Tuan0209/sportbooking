------------------------------
 CÁCH CHẠY DỰ ÁN
------------------------------
1) MySQL: tạo DB "sportbookingg" và import file SQL trong thư mục gốc
   (file: "sportbookingg (9).sql" - bản mới nhất).

2) Backend (Spring Boot) - thư mục sport-booking-api:
   - Build : mvnw -DskipTests clean package
   - Chạy  : java -jar target/sport-booking-api-0.0.1-SNAPSHOT.jar --server.port=8081
   (Port 8081 vì 8080 có thể bị app khác chiếm; nếu muốn dùng 8080
    thì sửa lại baseURL ở sport-booking-frontend/src/shared/services/axiosClient.js)

3) Frontend (React + Vite) - thư mục sport-booking-frontend:
   - Cài  : npm install
   - Chạy : npm run dev   (mở http://localhost:5173)

------------------------------
 CẤU HÌNH DỊCH VỤ (sport-booking-api/src/main/resources/application.yaml)
------------------------------
- Ngân hàng nhận chuyển khoản (sinh mã QR VietQR): app.bank.*
  (đang để MB Bank demo - đổi sang số TK thật khi triển khai)
- PayOS: payos.client-id / api-key / checksum-key (đang để trống -> chạy
  chế độ mô phỏng; điền key thật khi có tài khoản PayOS)
- Cloudinary: dùng để upload ảnh (bill thanh toán, avatar, ảnh sân)
